About

Flowerstrap is a fast, Roblox bootstrapper. Its a upgraded version of Bloxstrap and details from fishstrap making it faster and lighter on your system.

Features

Integrations

  • Fully customizable Discord Rich Presence
  • Prompt to confirm when launching another Roblox instance

Bootstrapper

  • Memory trimmer with threshold & interval
  • Disable Roblox crash handler to reduce resource usage
  • Background updates
  • Auto-update Flowerstrap

Deployment

  • Force Roblox reinstallation

Mods

  • Customize cursors (ShiftLock, Arrow, IBeam, etc.)
  • Cursor sets with easy import & export

Other

  • FFlag settings & FFlag editor
  • Global Settings page
  • No analytics at all
